# Pull Request: New features of PELCA v1.3.0

## Date 
02/04/2024

## Description
This pull request details the major updates provided by the release of the version 1.3.0 of the PELCA software. 

### PySide6 librairy
The version 1.3.0 of PELCA is built upon the PySide6 Python librairy, instead of the tkinter librairy which was used for the previous version of PELCA (v1.1.2).  

### Plotly graphical librairy
The version 1.3.0 of PELCA embeds the Plotly graphical librairy while the previous version of PELCA used Matplotlib graphical librairy. The Plotly librairy provides more interactivity to the user with the output graphs generated by PELCA.

### Installation procedure & compatibility with different OS
The installation procedure of PELCA has been refounded and normalized with respect to the standards of software development.

The version 1.3.0 of the PELCA software allows the user to install PELCA on the three major operating systems (OS) : 
   - Windows
   - Mac
   - Linux

More details on how to install PELCA on the different OS are available in [Readme](README.md).

### Economic impact assessment
The version 1.3.0 of the PELCA software provides a new feature in the possibility for the user to assess the economic impact (cost / price) of a system along its life cycle. 

More details about the assessment of the economic impact can be found at [Example Overview](ExampleOverview.md).
